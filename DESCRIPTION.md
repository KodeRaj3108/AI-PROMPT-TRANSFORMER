# AI Prompt Transformer

**AI Prompt Transformer** is a browser-based tool that turns your rough, unstructured idea into five fully optimized prompts — each tailored to a specific AI model. Enter one prompt, click Transform, and instantly see side-by-side outputs for **ChatGPT**, **Claude**, **Gemini**, **Grok**, and **Cursor**. Every output card includes a one-click copy button and a **One-Click Test** button that deep-links directly to the corresponding AI platform. A built-in **History Log** saves every transformation to local Storage, so you can revisit and reload any past session in seconds. Built with HTML, Tailwind CSS, and the Claude API — no backend required.
